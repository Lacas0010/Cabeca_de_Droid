2. Cofre de Segurança DPAPI & PIN Lock




Criptografia Windows DPAPI, derivação PBKDF2/AES-256 e PIN de Bloqueio numérico para blindar suas credenciais.



DPAPI Vault
PIN 4 Dígitos
AES-256-GCM




                                    Todas as credenciais (`cookies.enc`, `config.enc`) são criptografadas com a API DPAPI do Windows vinculada ao seu usuário do SO. Você também pode ativar um PIN de Acesso nas Configurações: com o cofre bloqueado, nenhuma ação ou consulta a dados sensíveis é liberada.
